# Contributing to the Minigo Console

The console is maintained as part of
[minigo-storage/minigo](https://github.com/minigo-storage/minigo).
Raise console patches as [pull requests against this repository](https://github.com/minigo-storage/minigo/pulls),
with `main` as the base branch.

Suggestions, bug reports and patch requests go through
[GitHub issues](https://github.com/minigo-storage/minigo/issues). Only
authenticated GitHub users may submit issues or participate in discussions;
sign in to your GitHub account first. Project contact is handled through issues.

Follow the [Minigo contribution guide](../CONTRIBUTING.md) and the
[frontend development instructions](web-app/README.md) when preparing changes.
For security reports, follow the [security policy](SECURITY.md).
