# Minigo Console Security Policy

The console follows the [Minigo security policy](../SECURITY.md).
Report console security concerns through
[minigo-storage/minigo issues](https://github.com/minigo-storage/minigo/issues).
Only authenticated GitHub users may submit reports or follow-up comments;
sign in to your GitHub account first. All project contact is handled through issues.

Issues are public. Provide a non-sensitive summary and the affected version;
do not post secrets, personal information or exploit details that could put
deployments at risk. Follow the root security policy for the reporting and
disclosure process.
