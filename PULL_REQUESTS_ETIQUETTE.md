# Minigo Pull Request Guidelines

Raise [pull requests against minigo-storage/minigo](https://github.com/minigo-storage/minigo/pulls),
with `main` as the base branch, for server, console and documentation patches.
Sign in to your GitHub account to contribute.

- Keep each pull request focused on a single fix or improvement.
- Explain the problem, the resulting behavior and any compatibility effects.
- Link related issues and describe how you verified the change. Include tests
  where appropriate for code changes.
- Follow the existing code style and respond to review feedback.
- Use a draft pull request for work that is not ready for review.

Suggestions, patch requests and discussion of larger changes belong in
[this repository's issues](https://github.com/minigo-storage/minigo/issues).
Only authenticated GitHub users may submit issues or participate in discussions.
Project contact is handled through issues.

See [Contributing to Minigo](CONTRIBUTING.md) for the contribution process and the
[README](README.md#development-and-verification) for verification instructions.
