# Minigo 3.0.2

This security update rebuilds the server and bundled `mc` with Go 1.27.4.
It fixes the HTTP/1 request handling issue CVE-2026-97054. The server also
updates OpenTelemetry to 1.47.0 for CVE-2026-128085, which affects attribute
size limits. The Go modules use x/crypto 0.59.0, and the image uses the
refreshed official Alpine 3.24.4 digest.

The console is built with Node.js 24.22.3. The version of picomatch used by
Vite has no published fix for GHSA-fc5q-39xc-vjpf. The build now rejects
repeated extglob patterns before compiling them. The regression test checks
that ordinary file selection works and that the restricted syntax fails fast.
The full npm audit still reports the advisory through four build packages.

Pull `minigostorage/minigo:3.0.2` for Linux amd64 or arm64. Helm chart 5.4.2
selects this image for both the server and setup jobs. When upgrading from
3.0.0, also follow the [3.0.1 Helm upgrade notes](https://github.com/minigo-storage/minigo/releases/tag/v3.0.1).
