# Minigo 3.0.1

Security maintenance release for Linux amd64 and arm64. Storage formats, S3/admin
protocols and the existing image command/environment contract are retained.

- Rebuild the server and bundled `mc` with Go 1.27.3, including the compromised
  intermediate-certificate distrust fix (CVE-2026-111943).
- Refresh the digest-pinned runtime to Alpine 3.24.4 and current packages, fixing
  the flagged Brotli, musl, curl/libcurl and zlib vulnerabilities.
- Update `klauspost/compress` to 1.20.2, `x/net` to 0.62.0, `go-jose/v4` to 4.1.6
  and their required Go dependency versions.
- Redact sensitive debug headers and complete query strings. Session cookies are
  marked Secure when the configured public console URL uses HTTPS, including
  deployments that terminate TLS at a reverse proxy.
- Run image scans locally for focused security releases. Publication verifies
  the exact tested archives against local reports, SBOMs and acceptance evidence.

## Upgrade notes

Pull `minigostorage/minigo:3.0.1`, or pin the release's recorded digest. Keep the
existing command, environment and volume configuration. Never run two servers
against the same storage volume. The image retains its existing default user to
avoid changing ownership requirements during a patch upgrade; a tested restricted
runtime profile is documented in `docs/minigo-security.md`.

For HTTPS proxies, set `MINIO_BROWSER_REDIRECT_URL` to the public HTTPS console
URL. This controls cookie security without trusting spoofable forwarded headers.
Debug logs intentionally no longer expose query values or arbitrary header values.

The bundled Helm chart is version 5.4.1. It now uses Minigo for both the server and
setup jobs; verifies TLS; applies UID/GID 1000, non-root, default seccomp, dropped
capabilities and no privilege escalation; and uses a read-only root filesystem
with explicit writable mounts. Security contexts also apply to ephemeral storage.
Check existing volume access for UID/GID 1000 before upgrading the chart.

The chart no longer creates the public `console/console123` administrator by
default. **Existing accounts are not removed by a Helm upgrade.** If an earlier
installation created that account, remove it or rotate its password and review
its access keys explicitly. Saved Helm values may retain the old user definition
or upstream image overrides; remove those overrides when adopting these defaults.
TLS-enabled setup jobs require a trusted certificate matching the service name.

## Evidence and limits

The GitHub release carries the raw local image scans, reviewed assessments,
CycloneDX SBOMs, archive checksums, hardened runtime and browser results, and the
same-volume acceptance report. The receipt identifies the exact candidate run,
source commit and images. Go source scans and npm audit results are retained with
the candidate workflow.

The scanner still reports the locally fixed MinIO CSV-reader advisory and the
unused, unmaintained OpenPGP package. Raw findings remain visible, with bounded
reader regression coverage and an import/reachability check for OpenPGP.
The compatibility suite covers one node and one volume, 10,000 small objects,
a >5 GiB object, interrupted-write recovery and rollback. Distributed upgrades,
KMS and remote replication require deployment-specific qualification.
