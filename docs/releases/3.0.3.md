# Minigo 3.0.3

The 3.0.2 Linux images shipped Alpine's OpenSSL libraries at 3.5.9-r0.
This release rebuilds both architectures with a minimum of 3.5.9-r1 for
`libcrypto3` and `libssl3`. Alpine lists five fixes in that revision:
CVE-2026-88822, CVE-2026-88823, CVE-2026-95691, CVE-2026-95692 and
CVE-2026-107496. [Alpine 3.24 security database](https://secdb.alpinelinux.org/v3.24/main.json)

Pull `minigostorage/minigo:3.0.3` for Linux amd64 or arm64. Helm chart
5.4.3 selects this image for the server and setup jobs.
