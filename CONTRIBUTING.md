# Contributing to Minigo

Minigo is maintained independently in
[minigo-storage/minigo](https://github.com/minigo-storage/minigo). Suggestions,
bug reports and patch requests are welcome through
[GitHub issues](https://github.com/minigo-storage/minigo/issues). Only
authenticated GitHub users may submit issues or participate in discussions;
sign in to your GitHub account first. Project contact is handled through issues.

To contribute a patch, fork this repository, make your changes on a branch, and
raise a [pull request against minigo-storage/minigo](https://github.com/minigo-storage/minigo/pulls)
with `main` as the base branch. This applies to both the server and the console.

Keep pull requests focused, explain the change, link any related issues, and
include the checks you ran. See the [README](README.md#development-and-verification)
for build and verification instructions and the
[pull request guidelines](PULL_REQUESTS_ETIQUETTE.md) for review expectations.

For security reports, follow the [security policy](SECURITY.md).
